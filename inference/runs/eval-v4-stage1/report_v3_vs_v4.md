## 4. 弱类深度分析：目标未达成，根因是域错配

test 中 bottle/foam_board 的 GT **全部来自 TACO（陆地垃圾照片，11/13 框）**，而本轮补强数据是**水域域**（航拍/水面漂浮视角）。两个域中"瓶子"的外观分布（视角、尺度、光照、背景）差异显著：

| 类别 | 指标 | v3 | v4 | 解读 |
|---|---|---|---|---|
| bottle | R@IoU0.5 | 0.250 | **0.273** (3/11) | 召回略升 |
| bottle | P | 0.676 | 0.382 | 精确率崩塌 |
| foam_board | R@IoU0.5 | 0.111 | **0.154** (2/13) | 召回略升 |
| foam_board | P | 0.623 | 0.277 | 精确率崩塌 |

即：v4 的"瓶子"概念已向水域外观偏移，在陆地域照片上触发更频繁但质量更差（召回微升、精确率大降 → mAP50 下降）。**水域域数据无法修复水域域 test 上不存在的目标**——冻结 test 无法度量本轮补强的主目标。

佐证（外部 eval-v1/v2 水域场景，无 GT 检出率）：

水面漂浮垃圾检出率明显上升（+0.25/+0.20），排污口保持满检出——**对河道巡检的核心场景是正向的**；bloom/bank 样本量小（4-8 图）且对应细类零样本，波动大仅供参考。

## 7. 结论

1. **冻结 test 目标未达成**：bottle 0.221→0.143、foam_board 0.095→0.079，总体 mAP50 -1.8pt。弱类在 test 上的 GT 全部来自 TACO 陆地域，水域域补强无法在此度量，且造成概念偏移（精确率崩塌）。
2. **水域域主目标实际达成**：外部场景 debris 检出率 +0.25/+0.20，outfall 持平 100%——对河道巡检（水面漂浮垃圾识别、堆类判定）是净收益。
3. **v4 ≈ v3（整体），分布向水域偏移**：陆地域（TACO）与部分大目标类微降，glass 上升，FP 下降。两者无绝对优劣。
4. **协议缺口**：本轮冻结协议将 marine 全部 3774 图放入 train，导致**没有 held-out 水域测试集**可直接度量水域域逐类提升——debris 检出率是间接证据。

## 8. 下轮建议

1. **建立水域域 held-out test**：从 marine-debris640 valid/test（175 图）或新采集河道实拍中划出冻结水域测试集，直接度量 bottle/foam/plastic 水域逐类指标（v3/v4 均可复评）。
2. **TACO 域处理**：TACO 照片以陆地垃圾为主，与水域巡检目标错配且持续拖低指标——考虑降采样、或仅保留其水面子集、或作为负样本/辅助类。
3. **tiny 目标**：合成实例尺寸分布下探至 <0.1% 面积桶；或引入切片推理（SAHI）与更高输入分辨率（imgsz 960）对照实验。
4. **部署选择**：河道巡检（水域场景为主）建议 A/B 验证 v4；若以冻结 test 为准绳则保留 v3。两个 ONNX 均已产出（v3/v4），可并行登记由后端配置切换。
