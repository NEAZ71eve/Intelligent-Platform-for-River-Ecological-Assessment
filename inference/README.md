# 图像推理接入边界

M1 只交付文件校验、用户权限、模型登记、识别任务状态与后台工作进程接口。此目录暂不含权重和真实推理运行时；不随机生成植物类别，不把占位答案标为识别成功。

任务由业务 API 入库，独立管理命令消费：

```bash
scripts/manage.sh run_recognition_worker --once
# 持续消费：
scripts/manage.sh run_recognition_worker
```

M1 没有模型时，消费任务会保存明确的 `MODEL_NOT_CONFIGURED` 失败原因。演示只能证明上传和任务生命周期，不代表 M3 图像识别已完成。

M3 接入时在服务端评估 ONNX Runtime CPU 运行时，限定单工作进程、单任务并发及 CPU 线程数。至少登记模型版本、许可来源、制品 SHA-256、输入预处理、类别顺序与阈值；实际推理输出存入任务结果，由原有鉴权接口返回。训练、转换和准确率评估在开发环境完成，Web 进程不加载模型。模型文件放到不受版本控制的受控目录。

后续实现需同时覆盖：真实成功结果、低分无法确认、解码/运行错误、处理超时和工作进程重启恢复。当前不启用本地 LLM 或外部模型 API。
