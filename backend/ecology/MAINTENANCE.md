# 模拟批次维护

仅针对项目小时模拟生成器创建的过期批次。观测使用真实 API、数据集或人工来源时，不进入清理范围。工具会保守保护不认识的生成器和关系异常数据，不能作为通用数据删除接口。

## 保留策略

后台“生态数据 → 模拟批次保留策略”维护全局策略：

- 默认至少保留 30 天；可调整为 30–3650 天。批次观测终点、创建时间或完成时间有任何一项落在保留期内，整批保留。
- 默认每个 `(数据源, 场景)` 至少保留最近创建的 3 个成功批次；可调整为 1–100 个。
- 额外保留每组最新观测时间范围，以及每个监测站实际最新的成功批次；即使它们超过保留期也保留，避免新批次省略站点后误删该站最新演示数据。
- 正在运行、未知状态（包括 pending）的批次始终保留。
- 来源不是 `simulation`、不符合项目 `demo-<场景>` 来源和 `hourly-v1` 生成器签名、实际观测数与批次计数不一致、时间越界、跨来源、非示范区域或站点/地点/水体/指标关联不一致的批次均受保护。
- 只有成功或失败的终态批次，且不触发上述保护条件时，才是候选。

保留策略本身不安排后台定时删除；应用迁移、启动服务和打开查询页均不会触发清理。

## 后台使用

入口：`/admin/ecology/simulationrun/`，支持来源、场景、状态、日期与批次 ID/键查询，显示实际观测数量与历史记录数量。

1. 使用具有 `ecology.view_simulationrun` 和 `ecology.maintain_simulation` 权限的管理员登录；超级管理员具备这些权限。
2. 点击“保留策略与清理预览”。页面 GET 不生成计划、不删除数据。
3. 点击“生成清理预览”，核对候选批次、实际观测总量和每个受保护批次的原因。
4. 有候选时才出现确认表单；勾选确认并 POST 提交后执行。正式执行前应先备份数据库。

后台确认有 CSRF 校验。预览令牌签名、绑定操作者、有效期 15 分钟、仅能执行一次，不能复制给另一个管理员使用。策略、批次、观测或关联资料发生变化时，旧预览拒绝执行，必须重新预览。

“模拟批次清理预览”只读后台可查询操作者、候选批次 ID、观测数量、有效期与执行时间；不会保存或展示签名令牌。

普通批次页和观测页禁止直接增改删，避免绕过保留策略或破坏历史来源关系。模拟场景、站点、地点等正常后台维护仍按既有模型验证执行，并写入统一管理审计。

## 命令行

默认只预览；预览会保存一条短期确认记录与安全审计，不会删除批次或观测：

```sh
python manage.py maintain_simulation
python manage.py maintain_simulation --json
```

正式执行必须显式提供上一步返回的令牌（本机和服务器部署验收仅使用预览）：

```sh
python manage.py maintain_simulation --execute --token '<预览令牌>'
```

命令行令牌不能用于管理员页面，管理员令牌也不能用于命令行。未提供令牌、令牌过期、重复执行、状态变化均会返回失败，不删除任何数据。没有“强制删除”“任意批次 ID 删除”或跳过预览的参数。

## 一致性与边界

- 生成器和清理服务先获取同一个保留策略行锁，再按固定顺序锁定来源、区域、站点、指标等依赖；生成器在锁内重新读取和校验，避免等待期间管理员变更造成旧对象被使用。锁持有到观测和成功批次写入完成。生成失败仍保留失败批次，部分观测在保存点回滚。
- 预览/执行锁定批次、关联父记录和观测，按服务器端现状计算候选；执行时重新校验完整状态指纹和确切候选集合，不因时间流逝偷偷追加候选。
- 删除观测、删除批次、消费令牌和记录执行审计在同一个事务内。任何一步失败全部回滚；多个并发执行最多有一个成功。
- 只按已验证的 `simulation_run_id` 删除关联观测；批次外的历史导入记录不受影响，错误挂接的真实来源观测会保护整个批次。
- 一次最多预览 5000 个批次、25 万条批次关联观测；超过限制立即拒绝。适用于当前课程演示数据量，大规模历史库应先设计专门分区归档。
- 审计事件：`simulation.cleanup.preview`、`simulation.cleanup.execute`、`simulation.cleanup.rejected`；仅保存操作者、预览 ID、状态/错误代码和观测计数，不存令牌、观测正文或凭据。

## 验证

独立 PostgreSQL 测试覆盖：保留边界、每来源/场景和每站最新数据保护、模拟/真实数据隔离、错配关系、过期/篡改/重放/状态改变拒绝、CSRF 与权限、命令默认预览、删除事务回滚、并发重复执行、生成和清理互斥。运行时必须使用隔离测试库，禁止在手测库执行删除验收。

当前定向验证：25 项通过（19 项维护测试 + 6 项既有生成器回归），并通过 ecology 迁移一致性检查。
