# 管理统计、查询与业务审计

## 管理统计入口

部署后执行数据库迁移。Django 管理后台的「管理统计与查询」位于：

- 页面：`/admin/common/managementstats/`
- 同口径只读 JSON：`/admin/common/managementstats/data/`

采用 Django 管理员会话登录。小程序 Bearer token 不会获得管理会话权限。要求账号启用、`is_staff=True`，并满足以下之一：

1. 授予特定模型的 **view** 权限，仅显示该模型对应的卡片、筛选项和查询结果。例如 `knowledge.view_content` 只允许内容统计。
2. 授予 `common.view_managementstats`，允许查看下表全部**经过字段裁剪的统计及明细**。此权限不赋予模型修改、私人对话查看、审计日志查看等其他权限。

超级管理员可以查看全部。没有授权的普通 staff 访问页面和 JSON 均为 403。匿名和非 staff 登录由管理后台拒绝。JSON 禁止缓存，不提供跨域或小程序公开入口。

## 统一口径

| 指标 | 口径 |
|---|---|
| 当前总量 | 查询时数据库中仍保留的记录，不受日期筛选影响 |
| 窗口内创建 | 北京时间 `[开始日 00:00, 结束日 00:00)`，按 `created_at`；用户按 `date_joined` |
| 已发布内容、地点 | 查询时的发布状态；不是“本窗口完成发布”的事件次数 |
| 识别、河道任务状态 | 窗口内创建、查询时处于该状态的任务 |
| AI 提交/成功/失败 | 窗口内创建的 UsageLedger，按 `recognition / explore / learn` 分开；私人会话删除后仍保留的账目也计入 |
| AI 预占回合 | 仅 `queued + running` 的账目，不包含已完成回合 |
| AI 结算 token | 账目 `accounted_tokens` 合计，包含失败调用可能消耗或估算的数量 |
| AI 预占 token | 仅排队/运行中账目的 `reserved_tokens` 合计，不重复累加已结束账目的预留 |
| 模拟批次生成观测数 | 窗口内批次 `counts` 的合计，表示批次记载的生成数量，不是现存 Observation 行数 |

统计窗口与 AI 配额结算是不同概念：配额按照账目 `day`（入队当天的北京时间）结算，跨零点结束也不改账目日期。

删除账号、任务、内容，或执行保留期清理后，相关存量统计会减少。既有私人数据清理任务保留业务日志 30 天，LLM 账目按其独立保留规则清理。因此此功能不提供不可变的终身累计，也不把收藏数、浏览记录数假装为 PV/DAU。

所有统计只查询本地数据库，不请求 DeepSeek 或天气供应商，不读取 API Key。天气预算在天气数据模块后台单独查看。

## 查询参数

页面表单与 JSON 使用相同参数。默认为近 7 个北京时间自然日（包含今天）：

- `start=2030-04-02&end=2030-04-03`：仅查询 4 月 2 日；最多 366 天。
- `dataset=users|content|places|recognition|assessment|llm|simulation`：明细数据集。
- `status=`：有状态字段的模型支持其有效状态，例如 `succeeded`、`failed`，内容支持 `draft`、`published`。
- `scope=recognition|explore|learn`：仅 AI 用量账目支持。
- `page=1&page_size=20`：页码 1–1000；每页 1–100。

不接受任意数据库字段、排序表达式或 ORM 查询条件。明细字段固定白名单；不返回微信 openid、账号密码、用户名/昵称、会话 token、图片、用户提问、回答、模型快照、来源文章正文。内容标题和地点名称仅在具备对应权限时可见。

## 关键操作审计

`common.admin_audit.AuditAdminMixin` 放在 ModelAdmin 继承列表第一位：

```python
class ContentAdmin(AuditAdminMixin, admin.ModelAdmin):
    ...
```

覆盖后台新增、修改、单条删除、批量删除及内联新增/修改/删除。记录：事件、模型标签、对象 ID、操作者、操作类型、**变更字段名**、时间。字段值不记录；未知表单字段名会丢弃。即使修改文章正文、网关、用户密码，日志也仅保留字段名。删除操作者账号后 FK 置空，目标 ID 仍保留。

- 变更和审计记录使用同一数据库事务，提交后才对外可见；回滚一起撤销。日志写入失败会回滚对应变更。
- 组权限变更也接入审计；Django 独立修改密码表单单独记录 `password` 字段名，无效表单不记成功操作。
- 批量删除先锁定并快照被授权的对象 ID，再严格删除该快照；不会把执行期间新出现的匹配对象一起删除。
- 既有模型启停动作在模型服务中记录，Mixin 不再次包裹任意 action，避免重复记录及将失败/预览误记为成功。
- 模型注册/启停、河道检测启停及教学规则启停使用结构化 `audit_admin`，不记录模型配置值。
- 业务服务可继续调用原有 `audit(event, actor, target_id, **details)`，保留现有安全字段白名单，不改变调用兼容性。既有历史记录的新增结构字段为空，保留原始事件。
- 日志后台支持日期、事件、操作、目标模型筛选，事件/目标 ID/模型/操作者搜索；禁止新增、编辑、删除，包括超级管理员。自动保留期清理仍由运维命令执行。
- Mixin 只覆盖管理后台路径；批量业务服务或运维命令应在自己的事务内显式调用审计函数。它不声称记录所有 SQL 或数据库管理员操作。

## 验证

在独立测试数据库执行，禁止使用手动体验库：

```sh
QWEATHER_ENABLED=0 QWEATHER_API_KEY='' HYHQ_LLM_TEST_SUFFIX=audit \
  .venv/bin/python .runtime/run-llm-check.py test common.tests_management --noinput
```

覆盖权限裁剪和越权、后台会话与小程序令牌隔离、北京时间边界、三板块用量口径、账目保留、状态筛选、分页边界、脱敏、事务回滚、批量删除、内联变更、删除操作者、模型动作去重及日志只读。
