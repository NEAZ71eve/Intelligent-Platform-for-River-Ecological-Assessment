# DeepSeek 图像解读与追问：L01–L06

日期：2026-09-20。基线：`40740ee`。用户要求将 LLM 网关提前实施，先在本机开发和测试，不更新服务器。

## 已确定范围

- 提供方为 DeepSeek，模型 `deepseek-flash`，使用官方 HTTPS Chat Completions 接口；显式关闭深度思考。
- 密钥只由后端环境变量 `DEEPSEEK_API_KEY` 读取；环境总开关与管理配置同时启用且密钥已配置才能请求上游。
- 登录用户每天共最多 **5 个成功回合**，以入队时的北京时间日期归属；跨图片、跨会话、跨花卉和河道入口共享额度。
- 首次解读也占一回合。失败释放用户预留额度，但上游调用尝试及可能产生的 token 成本单独计量；不自动重试结果未知的请求。
- 先绑定已有、本人、未过期的花卉或河道识别任务；本地机器学习结果保持原样，AI 解读单独展示。
- 用户主动同意后选择是否附图；传必要文本和已净化图片，不传 OpenID、令牌或精确位置。原图 24 小时后失效，历史记录存在不等于原图仍可外发。
- 采用独立问答任务进程和轮询；不占用图像推理全局执行锁。无需本地 LLM、Redis 或向量数据库。

## 必测行为

1. 同一用户同日第六个成功回合被拒绝；不同入口和新会话不能绕过。
2. 并发请求与重复 request_id 不额外扣额度、不重复外发；幂等键复用不同输入返回冲突。
3. 北京时间跨日、旧日未完成请求完成后的记账日期保持正确。
4. 非本人任务/图片/会话不可访问；后台权限限制有效。
5. 失败任务返还用户回合；上游超时、不完整结果、429、余额不足等有明确状态，未知成本保守记账。
6. 原图过期不再外发；仅结果解读明确缺少图片，不用缩略图静默替换。
7. 删除会话、识别记录或账号时，不恢复已消费额度，不让稍后回写的响应重建私人记录。
8. 不记录密钥、图片 base64 或聊天正文到运行日志；模拟内容不被描述为实测。
