# 高德与百度数据接入方案

核对日期：2026-09-21。本轮完成调研，不新增地图 API 调用或付费服务。

## 建议路线

先接入一个供应商，完成天津三所大学的真实地点资料、地址查询与步行路线，再决定是否需要另一家。结合个人毕设规模，可优先验证高德 Web 服务；百度作为替代候选。选择依据是当前搜索配额和功能契合度，不意味着任何一家的地图更准确。

现有静态生态导览与真实地图应当作为两个明确的模式。原示范河流、湖泊、水质不能挪到真实校园上；真实地图先展示经过核对的校园、公共公园和景点，自建生态监测点在拿到实际数据后单独增加。

## 账号与密钥

| 项目 | 高德 | 百度 |
| --- | --- | --- |
| 本项目 Django 服务端调用 | 申请 Web 服务 API Key | 申请服务端 AK，仅启用所需服务 |
| 服务器限制 | 配置出站公网 IP 白名单；北京主机需核对实际出口 IP | 配置 IP 白名单或文档支持的 SN 校验；使用 SN 时 SK 仅放后端 |
| 本地测试 | 建议独立测试 Key 与更低预算，不放宽生产白名单 | 建议独立测试 AK；不以任意 IP 通配替代生产保护 |
| 原生微信 SDK/插件（如果后续选用） | 按对应微信产品重新申请相应类型和权限，不混用 Web/JS Key | 微信小程序类型 AK 需绑定小程序 AppID，不能当作服务端 AK |

依据：[高德 Web 服务入门](https://lbs.amap.com/api/webservice/gettingstarted)、[高德 IP 白名单错误码](https://lbs.amap.com/api/webservice/guide/tools/info)、[百度 AK 类型与申请](https://lbsyun.baidu.com/index.php?title=FAQ-obtainAK)、[百度小程序密钥](https://lbs.baidu.com/docs/jsapi?title=wxjsapi%2Fguide%2Fkey)。

建议环境字段：`MAP_PROVIDER`、`AMAP_WEB_KEY`、`BAIDU_SERVER_AK`、需要时 `BAIDU_SERVER_SK`、分接口日/月请求上限。字段由下一批实现，当前无需向项目提供更多密钥。

## 第一批接口和额度

| 能力 | 使用方式 | 约束 |
| --- | --- | --- |
| 正地理编码 | 管理员核对校门/地点地址 | 不批量爬取全城地点 |
| 逆地理编码 | 用户主动定位后确认当前区域 | 定位失败仍可手动选择；不保存完整用户轨迹 |
| 地点检索/详情 | 限天津、北京及已选校园附近的具体查询 | 搜索防抖、分页上限、按供应商分别记账 |
| 步行路线 | 用户主动选择起终点后查询 | 自编科普路线与供应商道路路线分别标记；预设线路不假装实时可通行 |
| 坐标转换 | 按输入和展示产品要求转换一次 | 记录原坐标系与转换来源，防止重复偏移 |

截至核对日，高德官网个人认证非商业目的月配额表列出基础 LBS **150,000 次/月**、基础搜索 **5,000 次/月**；基础 LBS 多种能力共享预算。免费适用资格和期限需要在实际账号控制台确认，不能仅据公开表假定永久免费。[高德配额和服务许可](https://lbs.amap.com/upgrade)

百度公开权益表（页面标注更新于 2025 年 10 月）列出个人开发者地理编码 **5,000 次/日**、逆地理编码 **300 次/日**、地点检索 **100 次/日**、路线规划 **5,000 次/日**，这些服务并发为 **3 次/秒**。应以账号开通时显示的实际权益和当前计费说明为最终依据。[百度开发者权益](https://lbsyun.baidu.com/solutions/privilege)

下一批可采用保守应用预算：高德搜索 3,000 次/月、其他基础接口合计 10,000 次/月；若选百度，搜索 60 次/日、逆编码 150 次/日、其他接口各 500 次/日。**这是项目建议值，不是平台承诺的免费配额**。所有失败请求也预占，不自动购买或充值，不用多账号规避平台限制。天气继续使用和风，避免重复接两套天气数据源。

## 坐标与数据许可

每个点至少保存 `provider`、`provider_place_id`、`coordinate_system`、坐标、来源、获取/核对时间、公开状态。高德使用 GCJ-02；百度接口按 `coordtype`/返回坐标参数规范处理 BD-09 或 GCJ-02；天气当前使用 WGS84 区域点，不能直接用地图坐标替代。[高德坐标转换](https://lbs.amap.com/api/webservice/guide/api/convert)、[百度坐标转换](https://lbsyun.baidu.com/docs/webapi?title=geoconv/guide/changeposition)

地图 API 提供的是地点和出行资料，不能补出溶解氧、pH、浊度、校园实时环保传感数据。校园名称、地址与图文介绍仍要核对来源和使用权限。

供应商地图底图、POI、路线等内容的存储、缓存、再分发、跨供应商展示有授权边界。不能直接把天气模块的长期缓存方式照搬到地图，也不把抓到的地图信息构建成离线 POI 库。首批实现前核实所选 API 的实际条款；自有且有权限的地点资料与供应商返回内容分表管理，保留来源和必要署名。[高德服务协议](https://lbs.amap.com/pages/terms/)、[百度官方条款入口](https://lbsyun.baidu.com/solutions/privilege)

原生小程序底图和定位能力由微信提供，不会因为调用百度或高德搜索接口自动变成对应供应商的底图。混合展示前需确认所选产品授权允许，否则选择相应官方产品，或只对自有坐标使用微信原生地图。[百度微信小程序 FAQ](https://lbsyun.baidu.com/index.php?title=FAQ%2Fwxjsapi)
