# HYHQ 硬缺口数据自采规范 v1.0

> 适用范围：方向 B 四类补齐计划中**无公开数据**的 5 个细类。
> 调研结论：sewage_color / foam_pollution / algae_mass / bank_encroach 无公开 bbox 数据，bank_garbage 缺岸边视角——均需自采。
> 采集团队默认使用**手机巡河视角**（用户调研语境确认：岸边/手机视角，排除道路 dashcam、排除显微/卫星遥感）。

## 1. 采集目标总览

| 细类 | 归属大类 | 最小样本量 | 优先级 | 说明 |
|---|---|---|---|---|
| algae_mass | bloom_blackwater | ≥500 张 | P0 | 藻类团/水华，无任何公开数据 |

## 2. 拍摄采集规范

### 2.1 视角与设备
- 设备：手机（主摄）+ 可选运动相机/无人机（补充俯视视角）
- 视角：岸线巡河视角（约 1.5m 人眼高度，平视/略俯视水面与岸线）
- 画面：目标应占画面合理比例（长边 ≥ 30px 像素目标），避免过远过小

### 2.2 场景多样性（硬性要求，防过拟合）
- **地点**：≥5 个不同河段/河道；训练与验证/测试**按地点分组**（test 必须含训练未见地点——方向 B 泛化门禁）
- **时间**：白天不同时段（早/午/傍晚）、不同天气（晴/阴/雨后）
- **季节**：如条件允许跨季节采集（藻类水华夏季高发、黑臭秋冬明显）
- **光照**：顺光为主，避免正逆光导致目标不可辨

### 2.3 各类别拍摄要点
| 类别 | 拍摄对象 | 要点 |
|---|---|---|
| algae_mass | 水面藻类聚集团块、浮萍覆盖、水华连片区域 | 近景特写 + 中景场景都要有；避免纯绿水面远景（框内须可辨结构） |
| sewage_color | 水体异常颜色（黑/灰黑/棕褐/乳白浑浊）、水面油污膜 | 重点拍**变色明显**区段；同一河段多角度；避免把正常阴天暗水面误采 |
| foam_pollution | 水面白色/黄褐色泡沫堆积、浮渣层、岸边泡沫线 | 泡沫团块近景 + 泡沫带远景；雨后泡沫高发期优先 |
| bank_encroach | 岸线违建（彩钢房/简易棚）、岸线乱占（堆料/围挡/养殖棚）、岸线硬化破坏 | 岸线全景 + 局部特写；框目标是"侵占结构体"而非背景；避免把正常护岸当正例 |
| bank_garbage | 岸边垃圾堆积（袋装垃圾/建筑渣土/杂物堆）、水面漂浮物聚集岸边 | 岸边 0-5m 范围；区分"岸边堆积"与"水面漂浮"（前者 bank_garbage 后者 floating_debris） |

### 2.4 拍摄禁忌
- 不拍人像特写/人脸（画面中有路人时保持远景或后期裁剪掉人）
- 不拍车牌、门牌号等个人信息
- 不涉敏感区域（军事管理区、政府机关周边）
- 注意自身安全：不下水、不攀爬，河岸湿滑区注意防滑

## 3. 标注规范

### 3.1 类别定义（与 class_mapping.yaml 对齐）
15 细类中自采涉及的 5 类：

| 细类名 | 定义 | 反例 |
|---|---|---|
| algae_mass | 藻类/水华在近岸或水面形成的团块或连片覆盖 | 单株水草、浮萍零星 |
| sewage_color | 因污染导致的异常水体颜色（黑/灰/棕/乳白）或油污膜 | 正常水体因光线偏暗 |
| foam_pollution | 水面泡沫堆积/浮渣层/泡沫线 | 岸边白色垃圾（归 bank_garbage） |
| bank_encroach | 岸线人为侵占结构（违建、棚、堆料、围挡）| 正常护岸/栏杆 |
| bank_garbage | 岸边 0-5m 垃圾堆积 | 水面漂浮物 |

### 3.2 标注格式
- YOLO 格式（与现有流水线一致）：`class_id cx cy w h`（归一化坐标）
- bbox 覆盖目标**完整可见主体**，紧贴边缘（≤2px 冗余）
- 同一图中多个目标 → 多个框；同类重叠目标允许互相包含（遮挡合理）
- 类别判定歧义时：按上文"定义/反例"表裁决；无法判定 → 不标该框并在台账记录

### 3.3 质量门禁（方向 B 标签门禁）
- **双人独立标注**：每张图由 2 名标注员独立标注
- **一致性要求**：IoU ≥ 0.5 且类别一致的比例 ≥ 90%；低于则返工
- 不一致样本：第三人仲裁后写入最终标签
- 抽检：10% 样本由审核员复核，错误率 > 5% 则该批次返工

## 4. 数据组织（落 D 盘）

```
D:\HYHQ_data\self_collected\
├── images\            # 原始照片（命名：{类别}_{地点}_{日期}_{序号}.jpg）
│   ├── train\         # 按地点分组划分
│   ├── val\
│   └── test\          # 必须含训练未见地点
├── labels\            # YOLO 标签，与 images 镜像
│   ├── train\
│   ├── val\
│   └── test\
├── raw\               # 未筛选原始照片（保留备查）
├── annotation_ledger.xlsx   # 标注台账（双人标注记录、仲裁结果）
└── README.md          # 采集元数据（地点/时间/设备/天气）
```

**划分原则**：按地点分组（同一河段只进一个 split），train:val:test ≈ 8:1:1。

## 6. 工具建议
- 标注工具：Label Studio / X-AnyLabeling / CVAT（任选，导出 YOLO 格式）
- 采集记录：手机相册 + 批次说明（地点/日期/天气），或直接用「一羽」等巡河 App 的水印模式
