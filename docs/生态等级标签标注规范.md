# HYHQ 生态等级标签标注规范 v1.0

> 适用范围：方向 B 多任务模型的**图像级生态等级标签**（检测框 + 等级分类双任务）。
> 定位依据：训练方向报告（inference/reports/training-direction-v1.md）——方向 B 需要"每图生态等级标签 + 检测/等级多任务模型"。
> 该标签与检测标注**同步进行**，同一张图同时产出 bbox 与等级标签。

---

## 1. 标签体系

**四级等级**（每张训练图必须且只能标 1 个）：

| 等级 | 代码 | 判定标准（任一满足即算） | 示例场景 |
|---|---|---|---|
| good | 0 | 无明显污染/漂浮物/水华/黑臭/岸带问题；水体清澈或仅极少量自然漂浮（落叶、零星水草） | 清澈河道、正常岸线 |
| fair | 1 | 存在轻微问题：少量漂浮物（≤3 个）、轻微藻类、轻度岸边垃圾，但不构成明显生态恶化 | 有零星水瓶/包装、局部浮萍 |
| poor | 2 | 明显问题：多处漂浮物/较大藻类团块/明显水色异常/岸线侵占迹象，但未完全恶化 | 水华连片、漂浮物成串、岸边成堆垃圾 |
| critical | 3 | 严重恶化：黑臭水色、大范围水华覆盖、泡沫污染、密集垃圾堆、明显违建侵占，水面大面积被覆盖 | 黑臭水体、泡沫带、岸线违建棚 |

## 2. 标注决策规则

### 2.1 判定次序（自上而下命中即停）
1. **critical**：画面存在大面积黑臭/密集泡沫/大范围水华覆盖/垃圾堆积成灾任一 → 直接 critical
2. **poor**：存在明显但非灾难性的水华团块/多处漂浮物/岸线侵占/变色水域 → poor
3. **fair**：存在少量（≤3 处）漂浮物、轻微水色异常或少量岸边垃圾 → fair
4. **good**：以上均不命中 → good

### 2.2 关键原则
- **按最严重要素定级**：画面任一角落出现 critical 级要素（如黑臭段），整图按 critical 标，不取平均
- **等级与框联动**：框出 algae_mass/sewage_color/foam_pollution 等"生态恶化要素"时，等级不得低于 fair；框出多个恶化要素时趋向 poor/critical
- **镜头范围口径**：按画面可见内容评级，不推断画面外情况
- **不拍场景剔除**：纯风景无河道要素的图不入训练集（标注前先筛选）

### 2.3 分布目标
- 四级占比约束：每档 ≥ 15%（防止单档过少导致分类退化）
- 若自然分布不均衡，采集时对 poor/critical 定向补拍

## 3. 双人标注流程（方向 B 标签门禁）

```
原始图 ──► 标注员 A（bbox + 等级）──┐
          ├─ 标注员 B（bbox + 等级）──┼──► 一致性比对
          │                            │
          └───── 一致 ──► 写入最终标签 ┘
             不一致 ──► 第三人仲裁 ──► 写入最终标签
```

### 3.1 一致性要求
| 维度 | 指标 | 阈值 |
|---|---|---|
| 检测框 | IoU ≥ 0.5 且类别一致 | ≥ 90% 图片通过 |
| 等级 | 完全一致（等级差 0） | ≥ 85% 图片通过 |
| 等级容忍 | 等级差 ≤ 1（如 fair/poor 之间）| ≤ 10%（超出即返工）|
| 等级冲突 | 等级差 ≥ 2（如 good/critical）| 必须全部仲裁 |

### 3.2 仲裁规则
- 第三人（标注组长）对不一致样本重新标注
- 等级差 ≥ 2 的样本：以"最严重要素判定"复核（见 2.1），必要时回看原始照片
- 仲裁结果写入台账，标注员 A/B 的不一致率作为质量统计

### 3.3 质量抽检
- 每批次抽 10%，由组长复核；等级错误率 > 5% → 全批次返工
- 每周汇总一致性趋势，标注员持续不一致的类别 → 组织校准会议

## 4. 输出格式与落盘

### 4.1 文件结构（与检测数据同目录）
```
D:\HYHQ_data\self_collected\
├── images\{train,val,test}\     # 图片（与检测任务共用）
├── labels\{train,val,test}\     # YOLO 检测标签（已有规范）
└── eco_labels\
    ├── train.txt      # 每行: 图片路径 + 等级(0-3)，与 images 顺序对应
    ├── val.txt
    ├── test.txt
    └── ledger.xlsx    # 双人标注/仲裁台账
```

### 4.2 格式示例
```
D:/HYHQ_data/self_collected/images/train/algae_mass_河A_20260801_001.jpg 2
D:/HYHQ_data/self_collected/images/train/sewage_color_河B_20260901_002.jpg 3
```

## 5. 标注工具建议
- 检测 + 等级一体：Label Studio（自定义 label config，bbox 任务 + 单选分类任务）
- 纯等级标注：任何图片批量工具（如 Exif 备注 → 批处理脚本生成 txt）
- 双人管理：飞书多维表格登记任务分配与仲裁记录

## 6. 里程碑
| 阶段 | 内容 | 验收 |
|---|---|---|
| 试点批次 | 50 张/类 双人标注全流程 | 一致性达标、流程跑通 |
| 主标注 | 全量自采图 + 已有数据（IWHR 等）补标等级 | 各级 ≥ 15%，一致性 ≥ 阈值 |
| 质量审计 | 组长抽检 + 仲裁台账审计 | 错误率 ≤ 5% |
| 冻结发布 | 标签冻结、划分固定（seed 42）| 进入多任务训练 |
