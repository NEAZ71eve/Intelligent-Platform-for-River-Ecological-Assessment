# M2 核心展示实施计划

日期：2026-09-20；起点：河道整合及北京修复版本 `358e222`。用户要求继续原开发计划，并维护可执行的任务拆分。

## 本轮交付：生态导览、智慧河湖、数据中心

M1、M3 和河道图像观察已能本地运行。原 M2 的数据浏览仍有明显缺口：导览只有装饰图，河湖详情只有部分原始记录，缺少完整趋势与数据中心。本轮优先补齐这条用户路径：

**首页选择区域 → 静态导览选择地点 → 智慧河湖选择水体和监测站 → 查看四项指标与缺失断点 → 数据中心切换来源、批次和时间范围。**

天气、空气、水环境继续使用明确标注的模拟数据。公开浏览无需登录；河道照片识别保留为独立入口。部署、真实数据供应商、真实微信位置能力和模型实拍评估各有待办承接。

### 数据正确性约定

- 一个查询只选一个来源；模拟数据额外固定一个成功批次。批次之间不拼接曲线。
- 聚合覆盖所选完整时间窗口；点数限制通过时间桶实现，不取前若干条冒充全量。
- `null` 与数值 0 分别显示。质量可疑数据和缺失桶有提示，不形成未经说明的连续趋势。
- 最新值显示其实际观测时间；选旧批次时明确是历史窗口，不称“当前实况”。
- 图像观察的教学规则分与监测指标分开，不从四项模拟指标推断官方水质等级。
- 地图图片与相对坐标绑定版本；后台替换已绑定的底图内容应新建版本，避免点位偏移。

### 验证层级

1. **自动测试**：参数/权限、来源隔离、聚合与缺失、相对坐标、异步页面状态。
2. **本机联调**：真实 PostgreSQL、API、模拟批次和小程序 wx mock，记录各场景实际结果。
3. **微信端验收**：开发者工具/真机检查 canvas、缩放、点位、滚动、文字布局；未实际执行时保持待验。
4. **目标服务器验收**：北京 Debian 13 / 2核2GB 已完成基线内部测试，M2 本轮不部署；后续单独授权后再做服务器与公网验收。
