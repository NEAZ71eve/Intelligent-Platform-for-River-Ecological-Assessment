### 数据正确性约定

- 一个查询只选一个来源；模拟数据额外固定一个成功批次。批次之间不拼接曲线。
- 聚合覆盖所选完整时间窗口；点数限制通过时间桶实现，不取前若干条冒充全量。
- `null` 与数值 0 分别显示。质量可疑数据和缺失桶有提示，不形成未经说明的连续趋势。
- 最新值显示其实际观测时间；选旧批次时明确是历史窗口，不称“当前实况”。
- 图像观察的教学规则分与监测指标分开，不从四项模拟指标推断官方水质等级。
- 地图图片与相对坐标绑定版本；后台替换已绑定的底图内容应新建版本，避免点位偏移。

### 验证层级

1. **自动测试**：参数/权限、来源隔离、聚合与缺失、相对坐标、异步页面状态。

3. **微信端验收**：开发者工具/真机检查 canvas、缩放、点位、滚动、文字布局；未实际执行时保持待验。
4. **目标服务器验收**：A 批次当时仅本地交付；后续已部署北京 Debian 13 / 2核约2GB，并完成内部回归和真实接口联通。公网 HTTPS、真实微信登录、完整手机流程和正式负载验收仍单独保留。
