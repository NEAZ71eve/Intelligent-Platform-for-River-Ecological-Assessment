macOS / Apple M2，Python 3.12.6、Django 5.2.17、PostgreSQL 17.9、ONNX Runtime 1.23.1、Node.js 20.19.6。本机数据库仅监听 `127.0.0.1:55432`。


结果：**125 项后端测试、58 项前端测试全部通过，无跳过**；Django 系统检查、迁移漂移检查和差异空白检查通过。`assessments.0001_initial` 已在本机 PostgreSQL 实际迁移。

重点覆盖：

- 私有任务、图片和位置的所有者限制，过期清理、删除及账号注销。
- 不定位、手动关联、坐标配对/有限值/范围校验、同坐标系匹配、隐藏地点不泄露。
- 两类任务合计容量；PostgreSQL 中两个不同用户同时争用最后一个名额，结果恰为一次创建成功和一次 `QUEUE_FULL`。
- 模型与规则独立启停、完整快照、历史公开版本和后台权限；重复初始化保留已启用规则。
- 标准 ONNX 图、真实小型测试图推理、哈希/配置摘要、越界路径、非有限输出、候选边界、硬超时和锁继承。
- 框并集面积不重复计算，空检测和低图质没有分数，未支持类别不生成污染成因。
- 两类消费者处理期间删除或过期不会保存成功结果，已删除任务不会被恢复。
- 前端百分比检测框、位置拒绝/取消、页面卸载、登录变化、401、旧异步响应和删除后预览清空。

## 明确保留的验收项

- 真实微信登录、位置接口权限、隐私授权、开发者工具和真机布局尚未验证；wx mock 不替代微信端验收。
- Debian 13 首尔实例、HTTPS、合法域名和 2 核 / 4GB 整机负载尚未部署验收。
- 未做真实河道的独立精度评估；上游训练日志、训练/验证拼图和本机链路通过均不代表实际巡查精度。
- 只开放 class 9 漂浮物；塑料材质、水色、排污口等其他输出头没有作为可用能力发布。
- 规则分是教学规则，框面积是图像矩形代理，不能作官方水质等级、实际污染覆盖率或污染源判断。
- 示范水体没有实际坐标时附近匹配为空；仍可手选或不关联，不虚构真实监测关系。
