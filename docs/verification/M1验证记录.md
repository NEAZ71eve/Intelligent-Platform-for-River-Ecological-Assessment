## 验证中修复的问题

1. 资料 PATCH 使用事务内重新加载并锁定用户，避免旧请求把刚关闭的浏览记录重新开启。
2. 识别任务使用全局共享锁行限制队列，避免不同用户并发绕过容量限制。
3. 可信单层代理部署按覆盖后的客户端 IP 限流，避免所有用户共用代理 IP 的额度。
4. PostgreSQL 测试中的流式响应通过 Django 测试迭代器消费，避免手工关闭响应误关闭测试事务连接。
