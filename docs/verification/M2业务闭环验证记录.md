## B04：个人中心、隐私与反馈

- 个人资料、头像上传/下载、昵称修改和登录结果绑定发起会话与页面代次；旧账号返回不能写进新账号。退出/注销确认绑定原账号，防止切换账号后确认旧弹窗。
- 个人中心返回时等待已经接受的资料修改完成；手动刷新与再次修改同样受等待约束。隐私开关保存失败会恢复已确认值。昵称与后端统一为最多 32 字。
- 新增“我的反馈”：提交 1～1000 字、本人分页查看处理状态/答复、删除确认。失败保留草稿；结果不明确时提示先刷新核对。草稿、列表、确认和操作响应均隔离账号与页面生命周期。
- 管理员可按权限处理反馈并发布答复；自动记录处理人和时间，普通用户不能修改。仅有查看权限的管理员不能处理。待处理答复草稿不会通过用户 API 泄露。
- 新增迁移 `activity/0002_feedback_resolution.py`，只增加答复、处理时间、处理人字段，**不更改历史处理结论**。旧已处理记录缺少答复/时间时显示明确提示。
- 隐私说明同步反馈用途、访问范围、保留至本人删除/注销，以及关闭浏览记录只停止新增的行为。

### 已复现并修复的后端并发问题

1. 注销在删除子表后、删除账号前仍可能插入反馈，导致提交时外键错误。现在注销先锁当前有效账号，再收集和删除关联数据；与反馈/收藏/浏览/游览写入使用同一账号锁。
2. 资料更新后、写审计前释放账号锁，会与注销交错产生审计外键错误。资料修改与审计现在处于同一事务，使用锁后取得的账号对象。
3. 认证后的旧账号快照若已停用/删除，资料修改与注销明确返回 401；若已被提升为管理员，注销重新检查当前权限并拒绝。

新增 5 项隐私测试中包含两个使用独立 PostgreSQL 连接/线程的并发回归，先复现失败再验证修复；不使用 SQLite 推定行锁效果。两个并发用例验证顺序完成、无 500，以及注销后反馈、收藏、浏览、游览均无残留。

### 用户侧与后台实际 HTTP 验证方式

脚本：[m2-private-live-smoke.js](../../miniprogram/tests/m2-private-live-smoke.js)。需要显式开发登录，只能访问本机 `127.0.0.1`；创建两个临时开发账号，在结束时注销。

默认运行覆盖个人记录和反馈用户侧，输出 `admin_reply_verified: false`。要验证后台答复，在独立开发库中将 `HYHQ_FEEDBACK_HANDOFF` 指向一个尚不存在的本机临时文件；脚本写入本次反馈 ID 后最多等待 30 秒。测试操作者只处理该条本机反馈，然后脚本通过真实 API 检查答复和处理时间、删除记录并注销账号。文件只包含反馈 ID，不含令牌；脚本删除自己创建的交接文件。
