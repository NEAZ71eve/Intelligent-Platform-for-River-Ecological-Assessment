## B01：科普筛选与地点关联

- 基于既有分类和植物标签提供 `content-tags/`，不新增通用标签模型。文章支持区域、地点、分类、植物标签、标题/摘要搜索的组合筛选及稳定分页。
- 区域筛选包含该区域公开地点的关联文章，以及没有关联地点的通用文章。已隐藏地点的关联文章不作为通用文章加入区域筛选；全局公开浏览仍可读文章，地点 ID 和摘要均不返回。
- 科普页、文章详情和地点详情形成双向入口；地点仅预览少量关联文章，可跳到完整分页目录。资料出处可见；没有来源时不虚构出处。
- 科普后端原有 2 项加新增 14 项 PostgreSQL 测试通过后，继续实施 B02。

## B02：预设路线浏览

- 公开节点按 `order` 排序，隐藏/异常跨区域节点不返回；公开节点计数不泄露隐藏数量。路线列表和详情用预取避免每个节点各查一次数据库。
- 详情支持节点选择、上一站/下一站、查看地点和返回当前区域路线列表。返回时重新读取发布状态，已下架节点不会保留为旧入口；浏览选择不记录到访。
- 后端新增 10 项，knowledge 总计 **26 项通过**；前端科普 20 项、详情/路线 9 项加结构 3 项定向测试通过。
- 真实 HTTP 将目录分页设为 2 条：**8 篇文章分 4 页完整读取**，分类/植物标签/搜索组合正确；地点关联与 **6 个路线节点**的选择、跳转、返回均通过。公共浏览无登录、无定位，所有请求均为 GET。

## 环境与复现

Python 3.12.6、PostgreSQL 17.9、Node 20.19.6。独立本机库 `hyhq_m2_business_20260920`，API `127.0.0.1:18203`；不使用生产库。配置本地开发连接后运行：

```sh
scripts/manage.sh migrate
scripts/manage.sh seed_demo --start 2026-09-17T00:00:00Z --hours 48
scripts/manage.sh seed_recognition_knowledge
scripts/manage.sh test knowledge
scripts/manage.sh runserver 127.0.0.1:18203 --noreload
```

另一个终端执行：

```sh
cd miniprogram
node --test tests/knowledge.test.js tests/knowledge-detail.test.js tests/structure.test.js
node tests/m2-business-live-smoke.js
```
