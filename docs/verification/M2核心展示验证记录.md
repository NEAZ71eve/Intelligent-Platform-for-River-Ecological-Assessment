## 复现步骤

在独立本地 PostgreSQL 开发库配置好连接后，从仓库根目录运行；不要把以下初始化命令指向生产库。`scripts/manage.sh` 会进入 backend 目录并加载本地环境，数据库配置方法见 [后端说明](../../backend/README.md)。

```sh
scripts/manage.sh migrate
scripts/manage.sh seed_demo --start 2026-09-17T00:00:00Z --hours 48
scripts/manage.sh generate_simulation --scenario turbidity --start 2026-09-17T00:00:00Z --hours 48 --seed 20260916
scripts/manage.sh generate_simulation --scenario missing --start 2026-09-17T00:00:00Z --hours 48 --seed 20260916
scripts/check.sh
.venv/bin/python scripts/generate-demo-map.py --check
scripts/manage.sh runserver 127.0.0.1:18202 --noreload
```

另一个终端：

```sh
cd miniprogram
npm test
node tests/m2-live-smoke.js
```

HTTP 脚本仅允许 `http://127.0.0.1`。若端口不同，设置 `HYHQ_TEST_API`，例如 `http://127.0.0.1:8000/api/v1`。不需要微信凭据、开发账号或推理消费者。

本次实际使用 `.runtime/` 内受限的本机配置加载脚本，把上述 Django 命令指向独立库；测试输出保存在已忽略的 `.runtime/m2-full-backend.log`、`m2-full-frontend.log`、`m2-live-smoke.json`。可共享结果已复制到本目录。

## 复核中发现并修复的问题

1. 地图缩放后，旧尺寸的迟到位移事件可能污染下一次缩放中心。现在缩放、复位、resize 都以独立视口代号重建 movable 节点，事件校验节点自身代号。
2. 地图、河湖/数据中心、首页及详情的排队交互可能在隐藏/销毁后写状态或导航。新增入口保护及恢复显示后的加载测试。
3. 详情已成功读取收藏后，浏览历史保存失败会清掉收藏 ID。现在保留已确认收藏，只提示记录错误；回归验证下一次点击发 DELETE 取消收藏。

这些修复后重新执行前端全量测试和三场景 HTTP 联调，均通过。后端代码在完整 158 项回归后没有再变动。
