## 当前外部限制

直接公网HTTP仍收到腾讯云域名拦截页302，HTTPS443未通。不能把内网部署成功描述为正式上线。微信AppID已配置，服务端AppSecret仍为空，生产保持禁止开发模拟登录。因此普通微信用户的正式登录和真机公网AI使用还需：

- 域名备案/接入审核放行。
- 签发并配置有效HTTPS证书、验证自动续期；保持TLS验证与安全设置。
- 将实际微信AppSecret加入同一私有环境，配置小程序合法请求/上传域名并完成真机验收。

本机开发者工具仍可通过本机测试服务运行；本轮没有把本机小程序强制改到未放行的公网地址。

## 日常查看

通过已有管理员账号访问后台；在公网可用前沿用SSH受控访问/本机环境：

- 管理统计与查询：`/admin/common/managementstats/`。
- 关键操作日志：`/admin/common/auditlog/`。
- 模拟批次维护：`/admin/ecology/simulationrun/maintenance/`，先预览后确认。
- 天气查询地点、月度账本、上游请求、持久缓存：后台weatherdata分组。

运维命令需用受控环境加载器；不要source环境后打印，也不要把Key放在命令参数里：

```sh
python3 /srv/hyhq-releases/d4d0bed/deploy/run-production-command.py \
  --env-file /etc/hyhq/d4d0bed.env --release /srv/hyhq-releases/d4d0bed \
  manage.py maintain_simulation --json
```

这条命令只生成预览，不删除观测；显式执行需要未过期的签名令牌。保留策略默认30天、每来源/场景至少保留最新3个成功批次，同时保护每站最新数据。详细说明见 [模拟维护](../backend/ecology/MAINTENANCE.md)。

## 回退与再次升级

回退未实际执行，下列是操作边界：

1. 先进入503维护，停止新API入口并等待任务结算，备份新库、私有文件、环境与天气账本。任何新用户写入都不能直接丢弃。
2. 需要退到旧代码时，同步恢复旧版本的systemd、Nginx路径、旧环境和兼容数据库。旧LLM原本关闭，不得只把旧代码连接到新迁移库。
3. 对已有新业务数据先评估迁移/修复方案；本轮保留的旧库仅是切换前快照，不是可随时覆盖新数据的副本。
4. 天气账本和LLM用量账目属于费用约束，必须连续保留。旧版本没有天气功能；回退期间保持外呼关闭。后续再次启用天气必须继续使用最新完整账本，不能从切换前零账目快照重新开始计数。
5. 未来升级同样从当前最新数据库复制和迁移，保持本机100/服务器29,900的固定分配。新增环境必须先重新分配预算，不得独立复制Key和空账本。
