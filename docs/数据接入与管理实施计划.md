## 额度与数据边界

所有项目天气外呼必须经过持久账本。当前固定分配本机 100 次、北京 29,900 次，总计每月不超过 30,000 次；失败、超时也计入，缓存读取不计入。滚动 31 天限制进一步避免月边界时区差异。不得复制带同一 Key 的第三套独立账本、重建账本或恢复旧账本后继续发送请求。后续部署须保留已有计数；回退应先关闭天气外呼。此限制覆盖本项目，两套环境之外手动使用同一 Key 的请求不受项目网关控制。

目前仅按页面访问按需刷新，无定时全量预热。五地点即使全时段被访问，按天气 30 分钟、空气 60 分钟、预警 15 分钟缓存计算，31 天约 26,040 次，留有失败请求等余量；达到上限后继续标注展示可用旧缓存/不可用提示，绝不超额补抓。异常重试仍计入额度；新增地点前重新评估预算。

首页真实城市卡与原模拟观测使用不同接口、不同模型。校园名称只是查询区域的便捷入口，不宣称校内监测站，也不把模拟水质贴到真实大学名下。首版手动选择地点，不额外收集用户定位。

## 官方依据

- [和风 API Host](https://dev.qweather.com/docs/configuration/api-host/)、[认证方式](https://dev.qweather.com/docs/configuration/authentication/)。凭据 ID 不能替代 Key 或专属 Host；Key 只通过服务端请求头传递。
- [当前天气](https://dev.qweather.com/docs/api/weather/weather-current/)、[当前空气质量](https://dev.qweather.com/docs/api/air-quality/air-current/)、[预警接口目录](https://dev.qweather.com/docs/api/warning/)。采用当前 v1 文档，不能混用旧版 now 字段。
- [缓存建议](https://dev.qweather.com/docs/best-practices/cache/)、[来源注明](https://dev.qweather.com/docs/terms/attribution/)。保留上游署名和预警来源，区分获取时间与观测时间。
- 官方认证说明预告 2027 年 API Key 将有日请求限制，届时需复核并考虑迁移 JWT。
