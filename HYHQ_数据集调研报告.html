四、首选数据集详情（⭐⭐⭐ 立即可下载）

🏆 iSOOD — 排污口检测"黄金数据集" CC BY 4.0 outfall 主力

机构：清华大学环境学院 + 长江流域生态环境监督管理局（2024）
论文：Scientific Data, DOI: 10.1038/s41597-024-03574-9
下载：Zenodo 直链（9.5GB） · 代码 GitHub
规模：10,481 图（长江 9,285 + 黄河 1,196），YOLO txt 标注 + Excel 属性表（10 类排口：合流制/雨水/工业/农业/养殖/生活等）
视角：无人机低空近岸 + 手持相机。80% 大目标(>96px)。建议先用 iSOOD 预训练，再用少量自采岸边视角 fine-tune。

🏆 PoTATO — 水面塑料瓶专项 GitHub 直下 bottle 主力

机构：ECCV 2024 TRICKY Workshop（法国/巴西合作）
论文：Batista L.F. et al., "PoTATO", ECCV 2024 Workshops, DOI: 10.1007/978-3-031-91569-7_13
下载：GitHub · arXiv:2409.12659
规模：12,380 个水面塑料瓶标注实例，YOLO bbox，含偏振四通道（可提取 RGB）
视角：受控水池水面近距离平视，与 HYHQ 水面场景高度一致。是 bottle 类首选补充。

🏆 CANSURF — 水面金属罐专项 Zenodo 直下 metal 主力

机构：学术研究团队（USV/ASV 方向，2025）
论文："CANSURF: An ASV-View Can Dataset", arXiv:2605.16774
下载：Zenodo · GitHub
规模：~7,300 图（另一报告称 57,012 图训练集），ASV 无人船第一视角水面易拉罐，bbox + 跟踪 ID
映射：metal 类核心补充。

🏆 TACO — 类别最全面的通用垃圾集 CC BY 4.0 多类补充

机构：Universitat Pompeu Fabra, Barcelona（持续更新）
论文：Proença P.F. et al., arXiv:2003.06975
下载：GitHub · Zenodo · 官网
规模：1,500 图 / 4,784 实例 / 60+ 细类，COCO 格式（bbox + 分割 mask）
映射：bottle ✅ / plastic ✅ / paper ✅ / glass ✅ / metal ✅ / foam_board ⚠️（Styrofoam 近似）。需筛选水边/海滩样本。

🏆 AquaTrash — TACO 水相关子集 直下 4 类精准

机构：IIT Bombay（2023-2024）
下载：Ultralytics Platform · DatasetNinja
规模：369 图 / 469 框 / YOLO 格式 / 4 类：glass, metal, paper, plastic
价值：规模小但类别精准，直接面向水相关场景。

🏆 IWHR Floater V1 — 已有主力（补充藻类筛选） Figshare 直下

机构：中国水利水电科学研究院（2025）
论文：Qiao G. et al., Scientific Data 12:385 (2025), DOI: 10.1038/s41597-025-04594-9
下载：Figshare
规模：3,000 图 / 23,692 标注框 / VOC XML / 北京大运河岸基+手机视角
新发现：除 misc_debris 外，其中藻类/水草漂浮堆积样本可二次筛选为 algae_mass / water_plant 的弱参考。

七、按 15 细类的数据缺口与应对

🔴 完全空缺、必须自采的细类：
细类缺口原因推荐应对方案
algae_mass（藻类团/水华） 所有公开垃圾数据集中均无此独立标注类。WATER-DET 有 150 张但未公开。 ① 自采 ≥500 张（夏季河道绿色/蓝绿色漂浮藻华、水葫芦聚集）
② 用 IWHR 藻类筛选 + Roboflow algae-bloom 预训练
③ 邮件申请 WATER-DET 的 Algae Pollution 150 张
sewage_color（黑臭水色） 所有中文"黑臭水体"研究均基于高分卫星影像（GF-1/2、Sentinel-2），无岸边手持视角 bbox 标注。 ① 自采 ≥300 张（黑灰色水色河段）
② iSOOD 排口下游水色异常帧人工筛选
③ 邮件申请 WATER-DET 的 Sewage 150 张
④ 弱监督：HSV 空间颜色规则半自动提取候选区域
bank_encroach（岸线侵占/违建） 无公开专用数据集。Space-hehu 最匹配但未公开。 ① 邮件申请 Space-hehu（liuling@tjau.edu.cn，28,120 图含 engineering/greenhouse/building）
② 自采 ≥500 张（违建/堆料/围垦/护坡破坏）
③ 合成：从 xView/DOTA 裁剪建筑透视变换叠加河岸背景
④ 弱监督：Grounding DINO + SAM 自采视频伪标签
🟡 稀缺但有补充来源的细类：
细类公开数据覆盖补充建议
foam_board（泡沫板）Marine Debris Images (foam) + TACO (Styrofoam)，仅 2 个间接源下载 Kaggle foam 类 + 从 TACO 筛选 Styrofoam；自采 ≥200 张
fabric（织物）Underwater PP (glove/mask) + CleanSea (towel/rope)，均为近似类用近似类预训练 + 自采 ≥300 张（编织袋/衣物/渔网碎片）
water_plant（水草）River Flow Trash (grass) + Pasig River (aquatic plants)下载 River Flow Trash；自采中国河道本土场景 ≥300 张
glass（玻璃）TACO + AquaTrash + Underwater PP (gbottle)，水面场景稀缺三源组合，预计可获 1,000+ 框
paper（纸）TACO + AquaTrash + CoxPWD(packet 近似)三源组合；水面纸质垃圾罕见，量可能不足
🟢 数据充足的细类（多源可补）： bottle（PoTATO 12.3k + TACO + FloW-Img + 多个海滩集）｜ plastic（TACO + AquaTrash + YRDG + 多个集）｜ metal（CANSURF 7.3k + TACO + AquaTrash）｜ outfall（iSOOD 10,481 图直接覆盖）
